PROJECT | 2025

Curvature

A generative drawing system that layers sine- and cosine-based curves into intricate compositions, released as a curated NFT collection.

  • Project

    Curvature

  • Type

    Generative Art

    NFT Collection

  • location

    Malmö, Sweden

  • Released on

    OpenSea

  • dimension

    Variable

Inspired by Roman Verostko’s plotter drawing Bird in Flight, I developed a generative drawing system using p5.js that produces variable curved shapes through custom sine and cosine functions. The system evolves over time, generating increasingly complex, layered, and intricate compositions. It exposes parameters such as the number of curves, step count, and radius, allowing for a wide range of visual outcomes.

While the system is capable of producing countless variations, I curated a collection of 20 drawings, later released as the NFT collection Curvature. View the Curvature collection on OpenSea. The project also includes a virtual gallery space designed for the Curvature collection. Explore the virtual gallery on OnCyber.
